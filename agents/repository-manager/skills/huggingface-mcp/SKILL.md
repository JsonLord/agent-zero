# Hugging Face MCP Skill

## Capabilities

- Connects to the remote official Hugging Face MCP server at `https://huggingface.co/mcp` using `Authorization: Bearer ${ENV:HF_TOKEN}`.
- Search official Hugging Face documentation, models, datasets, and Spaces natively.
- Refer to official references:
  - https://huggingface.co/docs/hub/en/agents-mcp
  - https://huggingface.co/docs/huggingface_hub/en/guides/cli
  - https://huggingface.co/settings/mcp
