# Build fix — 2026-10-02

Two changes were made after the failed Hugging Face build.

1. `google-colab-cli` was changed from `0.7.1` to `0.7.4`.
   Version `0.7.1` is not available from PyPI, while `0.7.4` is a published release.

2. Agent Zero's PyTorch installation is now explicitly CPU-only:
   - `torch==2.5.1+cpu`
   - `torchvision==0.20.1+cpu`
   - installed from `https://download.pytorch.org/whl/cpu`

This prevents pip from pulling the large NVIDIA CUDA 13 dependency stack into the
OpenOperator CPU control-plane image.

No changes were made to the isolated Training Master, Soup, Kaggle, GitHub CLI,
or interactive OAuth design.
